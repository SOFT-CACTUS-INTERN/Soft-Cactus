## 📥 Installation

```bash
# Clone the repo
git clone https://github.com/SOFT-CACTUS-INTERN/Soft-Cactus.git

# Navigate to the project directory
cd Soft-Cactus
# Install dependencies
npm install
# Install the React dependencies
cd Cactus-Front
npm install
# Install Laravel dependencies
cd emailSending
composer install
#to activate the email Laravel api
cd emailSending/mailAPI
php artisan serve

# Start the development server
npm run dev
```
## 🧱 Project Structure

This project consists of two main parts:

- [`Cactus-Front/`](./Cactus-Front): A React frontend built with Vite.
- [`emailSending/`](./emailSending): A Laravel backend used for sending emails via API.

Each folder contains its own `README.md`, and instructions.
